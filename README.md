## 2. Free Hosting Options

### Option A: GitHub Pages (Recommended)

Since your GitHub username is **`venkat20017`**:

1. **Initialize Git & Commit**:
   ```powershell
   git init
   git add index.html README.md
   git commit -m "Add Venkatesh Prasad resume"
   ```

2. **Create a GitHub Repository**:
   - Go to [github.com/new](https://github.com/new).
   - Repository Name: `venkat20017.github.io`
   - Set to **Public**.

3. **Push to GitHub**:
   ```powershell
   git branch -M main
   git remote add origin https://github.com/venkat20017/venkat20017.github.io.git
   git push -u origin main
   ```

4. **Live URL**:
   Your resume will be live worldwide at:
   ```text
   https://venkat20017.github.io
   ```

### Option B: Netlify Drop (Instant — Under 1 Minute)

1. Open [app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop the `H:\resume host` folder onto the page.
3. Your resume is deployed immediately with a free HTTPS URL.
